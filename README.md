
# Yüz ve Göz Hareketleri ile Bilgisayar Kontrolü

## Kurulum
1. Python 3.10+ yüklü olmalı.
2. Gerekli kütüphaneleri yükleyin:
   ```
   pip install -r requirements.txt
   ```
3. `main.py` dosyasını çalıştırın:
   ```
   python main.py
   ```

## Özellikler
- Yüz hareketi ile imleç kontrolü
- Göz kırpma ile tıklama
- Sesli komutlar ile işlem yapma

## Sesli Komutlar
- "sağ tık", "sol tık", "çift tık", "enter", "çık" gibi komutlar desteklenir.
